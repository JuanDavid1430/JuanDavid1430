### 🚀 Sobre mí

Soy un desarrollador apasionado por crear soluciones tecnológicas que optimicen la productividad empresarial. Con **2 años de experiencia**, me especializo en transformar necesidades de negocio en software funcional: desde sitios web estáticos hasta sistemas complejos como **ERPs y Sistemas Integrados de Gestión (SIG)**.

Mi enfoque principal es la **automatización de procesos internos**, ayudando a las empresas a reducir tareas manuales mediante integraciones robustas, manejo de APIs RESTful y código eficiente.

- 🔭 **Actualmente trabajando en:** [DiscolmetsSAS](https://discolmets.com.co/) como Developer Full Stack.
- 🌱 **Aprendiendo:** Gestión Cloud con AWS, Azure y buenas prácticas de desarrollo (Clean Code).
- 💬 **Pregúntame sobre:** PHP8, SQL, Javascript, Angular, Bootstrap5 y TailwindCSS.
